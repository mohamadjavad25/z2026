# ریلز «کنسلی»: آماده، هنوز پست نشده

اولین ریلز پیج فرفرو (@frfronews). فیلم، صدا و کاور آماده‌ست و صاحب پروژه تأییدش کرده (۸ آبان ۱۴۰۵). **هنوز پست نشده.**

## قبل از پست باید این‌ها انجام بشه

- دکمه‌های تازه‌ی «بفرست به اینستاگرام» و «ذخیره عکس» که فیلم نشون می‌ده، باید روی سایت و اپ واقعی باشن. الان فقط روی شاخه‌ی `claude/story-studio` هستن و ادغام نشدن.
- نسخه‌ی تازه‌ی اپ اندروید باید توی کافه‌بازار منتشر بشه.
- یه بار روی آیفون واقعی، از سایت frfro.ir امتحان بشه که فرستادن استوری کار می‌کنه.
- مثل هر پست دیگه، قبل از پست صاحب پروژه باید «آره» بگه.

## فایل‌ها

- فیلم: `film-v5.mp4`، عمودی ۱۰۸۰×۱۹۲۰، ۵۶ ثانیه، با صدای گوشی فرفرو.
- کاور: `cover-jump.png`، کاراکتر با گوشی می‌پره. نوشته‌ها وسط کاورن تا توی صفحه‌ی پیج بریده نشن.
- فایل‌های کاری کامل (کلیپ‌ها، صداها، کاورهای دیگه) روی کامپیوتر صاحب پروژه هستن: `docs/brand/films/01-kanseli/` و `C:\Users\novin\frfro-films`.

## چطور پست کنیم

ریلز معمولی بذار، نه ریلز آزمایشی. چون این اولین پسته، باید روی صفحه‌ی پیج بمونه. «نمایش در فید» روشن باشه. کاور رو با «اضافه کردن از گالری» از `cover-jump.png` بذار. آهنگ رو از خود اینستاگرام انتخاب کن و صداش رو کم کن که صدای گوشی شنیده بشه.
