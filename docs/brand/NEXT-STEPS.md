# کارهای باز برند و اینستاگرام (برای ادامه در هر سشن)

آخرین به‌روزرسانی: ۲۰۲۶-۱۰-۲۰. هر سشن جدید Claude: اول همین فایل را بخوان و از اولین کار باز ادامه بده. با کاربر فارسی ساده حرف بزن؛ از گوشی دنبال می‌کند.

## انجام شده
- کاراکترهای قدیمی اپ حذف و ۹ ژست تازه با کاراکتر برند ساخته شد (AvalAI، مدل Pro). جزئیات: `docs/brand/CHARACTER.md` بخش «In the app». فایل‌ها: `public/brand/mascot/*.webp`، منبع‌ها در `docs/brand/poses/` (`raw/`، `clean/`، `p-app-*.txt`).
- `app/components/Mascot.jsx` حالا ژست‌ها را با پیامشان نام می‌برد (`connect`، `no-bookings`، `free-day`، `no-services`، `no-portfolio`، `saved-empty`، `lost`، `done`، `team`). همهٔ جاهای اپ و صفحهٔ معرفی عوض شد. نوار دسته‌ها در صفحهٔ معرفی حالا آیکن خدمات اپ را نشان می‌دهد.
- دوربُری تمیز: `scripts/brand/cutout/matte.py` (بدون حاشیهٔ سفید، بدون سایهٔ زیر پا).
- همهٔ این‌ها روی branch `claude/new-mascots` است، **هنوز با main ادغام نشده و روی سرور اصلی نرفته**.
- اعتبار AvalAI بعد از این کار: حدود ۲۷۸ هزار تومان (هر عکس Pro حدود ۳۷ هزار).

## کارهای باز، به ترتیب
1. **تست و انتشار کاراکترهای جدید.** روی branch `claude/new-mascots`: `npm run build` و تست‌ها (`npx vitest run`؛ Docker باید روشن باشد). لینک preview ورسل را به کاربر بده. فقط بعد از «اوکی» کاربر: ادغام با `main` و `scripts/deploy.sh`، بعد چک سایت زنده. (کافه‌بازار در حال بررسی اپ است؛ این تغییر فقط عکس است، دیتابیس و ورود دست نمی‌خورد.)
2. **عکس صفحه‌ها را از اول بگیر** (با کاراکترهای جدید). نسخهٔ نمایشی: کانتینر Docker `frfro-demo-db` (`docker start frfro-demo-db`)، فایل `.env.development.local` (در git نیست؛ متنش در `CHARACTER.md` نیست، این است: `POSTGRES_URL=postgres://postgres:demo@localhost:55432/frfro?sslmode=disable` و `FRFRO_SMS_PROVIDER=test`)، و پیکربندی `demo` در `.claude/launch.json` (پورت 3300). حساب‌های نمایشی: رمز همه `demo-pass-123`؛ مشتری مریم `09121110100`، سالن رز سپید `09121110001`، آرتیست سارا رحیمی `09121110011` (خدمات، نمونه‌کار و نوبت دارد)، آرتیست خالی نگار `09121110012`. ابزار عکس‌گیری Playwright (`flow.mjs`) در scratchpad سشن قبلی بود؛ اگر نبود، دوباره بساز: viewport 360×640، deviceScaleFactor 3، Edge، کوکی `frfro_session`، localStorage `frfro-entered=1`.
3. **سه پست آموزشی جدا** (قانون کاربر: هر آموزش فقط برای یک نفر؛ هرگز قاطی): «فرفرو برای مشتری»، «فرفرو برای سالن»، «فرفرو برای آرتیست». جلد هر پست بگوید برای کیست. ۱۰۸۰×۱۳۵۰، Vazirmatn، بخش‌های جوهری/روشن، عکس واقعی اپ در قاب گوشی، کاراکترهای تمیز از `docs/brand/poses/clean/` (پاها هرگز بریده نشوند). پوشه: `docs/brand/posts/NN-slug/`. پست ۱ قبلی را کاربر پاک می‌کند.
   - مشتری: پیدا کردن سالن و «وصل شو» → خدمت و ساعت → «ارسال درخواست» → «نوبت‌های من» → رایگان.
   - سالن: «داشبورد» و تأیید درخواست → خدمات و قیمت → پرسنل → «دعوت مشتری» → ۳۰ روز رایگان.
   - آرتیست: نمونه‌کار → خدمات → رزروها و تأیید/رد → همکاری با سالن (اسکن کد) → ۳۰ روز رایگان.
   هر پست را قبل از انتشار به کاربر نشان بده؛ روزی یک پست. انتشار با Composio (اکانت `frfronews`).
4. **پست «کجاست؟ با تپسی»** بعد از اینکه دکمهٔ تپسی (سشن جدا) روی سرور رفت.
