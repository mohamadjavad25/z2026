# Mascot sticker prompts

Generated by `node scripts/mascot-prompts.mjs` from the live icon list (109 icons, 19 sheets).

**How to use**
1. Open a chat with the image model that made the approved sample, attach the reference mascot image, paste one sheet prompt below.
2. Download the sheet PNG as-is (no re-compression), name it `sheet-01.png` ... and put it in `mascot/sheets/`.
3. Run `node scripts/slice-sticker-sheet.mjs mascot/sheets/sheet-01.png --ids <the ids line under the prompt>`.

Keep the same order left-to-right, top-to-bottom as written. If the model reorders or merges items, regenerate that sheet.
