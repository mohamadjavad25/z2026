# لحن متن‌های فرفرو (تصمیم صاحب محصول، ۱ آبان ۱۴۰۵ / 2026-10-23)

هر متنی که مشتری، سالن یا آرتیست می‌بیند (صفحه، دکمه، خطا، اعلان، پیامک) با همین قانون‌ها نوشته می‌شود.
متن قوانین و حریم خصوصی (`app/legal`) و پنل مدیر (`app/admin`) از این قانون‌ها بیرون‌اند.

## قانون‌ها

1. **با «تو» و خودمانی:** «رو»، «می‌خوای»، «می‌شه»، «نداری»؛ مثل حرف زدن، نه نامهٔ اداری. هیچ‌جا «شما» یا «کنید».
2. **اول کار، بعد توضیح:** دکمه می‌گوید چه می‌شود («بفرست»، «تأیید»، «بساز»)، نه «ثبت درخواست».
3. **یک جمله، حداکثر دو.** توضیح بیشتر، کوتاه و زیرش.
4. **یک اسم برای هر چیز** (جدول پایین).
5. **شوخی فقط جای خالی و آرام:** صفحهٔ خالی و پیام موفقیت. هیچ‌وقت در خطا، پول، لغو یا حذف.
6. **خطا بگوید چه کنی:** «اسم سالنت چیه؟» به‌جای «نام سالن را وارد کن.»
7. **عدد همیشه فارسی**، و کنار عدد نقطهٔ وسط (·، •) نه؛ ویرگول یا کلمه.

## شکل کلمه‌ها

| رسمی | فرفرو |
|---|---|
| را | رو |
| است / هستند | ـه، ـست / ـن («آماده‌ست»، «خالیه»، «تعطیله») |
| می‌شود، می‌کند، می‌دهد، می‌رود، می‌آید | می‌شه، می‌کنه، می‌ده، می‌ره، میاد |
| می‌خواهی، می‌توانی، می‌گویی | می‌خوای، می‌تونی، می‌گی |
| یک (به معنی «یه») | یه |
| اگر | اگه |
| تایید | تأیید (فقط در متن؛ مقدار وضعیت در داده «تایید شده» می‌ماند) |

## یک اسم برای هر چیز

| این را بنویس | نه این |
|---|---|
| نوبت (وقتی که گرفتی) | رزرو، رزرو نوبت |
| درخواست (تا سالن جواب نداده) | رزرو در انتظار |
| نوبت‌های قبلی | سابقه رزروها، تاریخچه رزروها |
| نوبت پیش‌رو | رزرو فعال |
| ذخیره‌شده‌ها | بوکمارک، لیست ذخیره‌شده‌ها |
| سالن و آرتیست‌هات | سرویس‌دهنده‌ها |
| مشتری‌هام | جامعه مشتریان |
| کد من | اسکن شو |
| نمونه‌کار تازه | ایجاد پست |
| جام روی نقشه | ثبت لوکیشن |
| وصل شو / وصل هستی | دنبال کردن |

«رزرو» فقط روی دکمه‌ای می‌ماند که نوبت گرفتن را شروع می‌کند («رزرو»، «رزرو «رنگ مو»»).

## چیزهایی که نباید عوض شوند

مقدارهایی که در داده ذخیره یا با آن مقایسه می‌شوند فقط در نمایش ترجمه می‌شوند، خودشان عوض نمی‌شوند: وضعیت‌ها
(«تایید شده»، «لغو»، «درخواست»، «تازه»، «منقضی شده»، «در انتظار مشتری»)، نام روزهای هفته، نام خدمت‌ها و کاتالوگ خدمات
(در داده ذخیره می‌شوند)، و هر متنی که کدی آن را با عبارت باقاعده می‌خواند.
