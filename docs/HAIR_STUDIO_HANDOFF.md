# استودیوی مو (تصویر هوش مصنوعی): تحویل نشست

تاریخ: ۱۹ آبان ۱۴۰۵. هنوز کدی نوشته نشده. این فایل فقط برای ادامهٔ کار در نشستی است که مرورگر دارد.

## ایدهٔ صاحب کار
استودیوی ساخت تصویر برای خانم‌ها، همان ایدهٔ اول فرفرو. کاربر عکس چهره‌اش را می‌دهد و مدل مو را یا با عکس نمونه یا با توضیح متنی. هوش مصنوعی بر پایهٔ چهره، جنس مو و حجم مو، مدل را روی خودش پیاده می‌کند. هدف: وقتی به آرایشگاه می‌روند، نتیجه را از قبل ببینند و به آرایشگر نشان دهند.

## چیزی که تا الان درآمده (از جستجوی وب، همه از منابع ثالث، باید با صفحهٔ رسمی تأیید شود)
- Gemini Flash Image (Nano Banana): حدود ۰٫۰۳۹ دلار برای هر تصویر؛ batch حدود ۰٫۰۱۹۵. مدل تازه‌تر Nano Banana 2 حدود ۰٫۰۴۵ تا ۰٫۱۵ بسته به اندازه.
- FLUX.1 Kontext Pro (fal.ai یا Replicate): حدود ۰٫۰۴ برای هر تصویر؛ Max حدود ۰٫۰۸.
- GPT Image (متوسط): ۰٫۰۴۲ مربع، ۰٫۰۶۳ غیرمربع؛ ورودی تصویر در ویرایش ممکن است جدا حساب شود.
- با تکرار و ردشدن‌ها (حدود یک‌چهارم) هزینهٔ هر نتیجهٔ خوب ≈ ۰٫۰۵ دلار.
- فرض دلار ۱۵۰٬۰۰۰ تومان (حدس، باید عوض شود) → ≈ ۷٬۵۰۰ تومان هزینه برای هر تصویر.

## پیشنهاد فعلی
- بستهٔ اعتباری (۳، ۱۰، ۳۰ تصویر) به‌جای پلن؛ ضریب قیمت حدود ۳ برابر هزینه؛ اولین تصویر رایگان. پلن ماهانهٔ سالن بعداً.
- زمان: نمونهٔ قابل‌دیدن ≈ ۵ روز؛ آمادهٔ انتشار ۴ تا ۵ هفته.
- مسیر: گوشی ← سرور فرفرو (اعتبار، صف) ← API مدل تصویر ← نتیجه (قبل/بعد). کلید فقط روی سرور.

## موانع
- API های Google/OpenAI/fal از ایران بسته‌اند؛ سرور اصلی ایرانی است. باید یک واسطهٔ خارجی باشد (مثلاً Vercel یا یک سرور بیرون). تصمیم و هزینه‌اش باید روشن شود.
- عکس چهره داده‌ی حساس است: رضایت، حذف خودکار، چیزی خارج از دیتابیس ذخیره نشود (قانون «رد پا» و بستهٔ انتقال سرور). پرسش حقوقی به agent `ecommerce-lawyer`.
- ریسک اصلی محصول: حفظ شباهت چهره و درست‌بودن جنس/حجم مو. اول باید آزمایش شود.

## کار این نشست (با مرورگر)
1. صفحهٔ قیمت رسمی هر سرویس را باز کن و عددها را تأیید یا اصلاح کن: Google Gemini API، Black Forest Labs / fal.ai / Replicate، OpenAI. اگر سرویس تخصصی «امتحان مدل مو» با API دارد (مثل Perfect Corp / YouCam، Banuba، Fotor و مشابه) آن را هم بنویس.
2. برای هر کدام بنویس: قیمت، محدودیت نرخ، شرط استفاده از چهرهٔ آدم‌ها، امکان پرداخت از ایران و راه واسطه.
3. با عکس‌های خود صاحب کار (یا عکس‌های نمونهٔ مجاز) یک آزمایش کوچک و یکسان انجام بده: همان چهره و همان مدل مو در هر سرویس. معیار: شباهت چهره، موی فرفری/صاف/حجیم، طبیعی‌بودن لبهٔ مو. عکس‌های کاربر واقعی هرگز نه.
4. نتیجه را به صاحب کار نشان بده (عکس کنار هم) و یک پیشنهاد روشن بده: کدام مدل، چرا، هزینهٔ واقعی.
5. بعد از آن، طبق قانون «پیش از ساخت بپرس»، ۳ تا ۶ سؤال محصولی با پاسخ پیشنهادی بپرس (محدودیت روزانه، چه نشان بدهد وقتی عکس نامناسب است، ذخیرهٔ نتیجه، چه کسی ببیند) و جواب‌ها را در `docs/DECISIONS.md` بنویس. بدون اجازهٔ صاحب کار چیزی نساز و به `docs/ROADMAP.md` اشاره کن.
