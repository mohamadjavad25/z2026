# فهرست کارهای پیش از انتشار

کارهای کدی بررسی پیش از انتشار (۱۸ اکتبر ۲۰۲۶) انجام شده‌اند (`docs/DEVLOG.md`). این‌ها می‌مانند: یا کار صاحب محصول‌اند، یا روی سرور تازه با هم انجام می‌شوند.

## روی سرور تازه، با هم (راهنما: `docs/DEPLOY_SERVER.md`)
- [ ] پیش‌نیازها: Node 22، Postgres، nginx، certbot، منطقهٔ زمانی تهران.
- [ ] `.env` با همان کلیدهای Vercel: `FRFRO_ADMIN_SECRET`، `FRFRO_ADMIN_PHONES`، `FRFRO_ADMIN_SETUP_KEY` و کلیدهای VAPID **همان مقدار** باشند.
- [ ] کپی دیتابیس از Supabase، بعد `npm run migrate`.
- [ ] برگرداندن عکس‌ها از Supabase Storage به دیتابیس (`scripts/pull-media-from-storage.mjs`).
- [ ] سرویس systemd، nginx با `X-Real-IP`، HTTPS با certbot، فایروال (پورت 3000 بسته).
- [ ] کارهای زمان‌بندی‌شده با crontab، بعد غیرفعال کردن workflowهای `cron-*` در GitHub.
- [ ] بکاپ شبانه، و **یک بار تمرین بازیابی** روی دیتابیس جدا.
- [ ] پایش `https://frfro.ir/api/health` با هشدار.
- [ ] وصل کردن دامنه به IP سرور، بعد خاموش کردن پروژهٔ Vercel (یا نگه‌داشتنش فقط برای ریدایرکت).

## کار صاحب محصول
- [ ] **پیامک:** حساب کاوه‌نگار یا فراز اس‌ام‌اس، الگوی کد تأیید، و دو الگوی نوبت (`BOOKING_REQUEST`، `BOOKING_ANSWER`؛ متن پیشنهادی در `docs/OPERATIONS.md`). کلیدها در `.env` سرور. اول با شمارهٔ خودت امتحان کن، بعد `FRFRO_OTP_REQUIRED=1`.
- [ ] **درگاه:** قرارداد زرین‌پال (یا درگاه دیگر)، مرچنت‌کد، و یک پرداخت واقعی کوچک **از روی سرور جدید**.
- [ ] **اینماد و ثبت کسب‌وکار:** درگاه معمولاً لازمش دارد. گرفتنش چند هفته طول می‌کشد، پس زود شروع کن.
- [ ] **قوانین و حریم خصوصی:** پیش‌نویس فعلی را وکیل ببیند.
- [ ] **مالیات بر ارزش افزوده:** قیمت‌ها با مالیات یا بدون.
- [ ] **کانال پشتیبانی بیرون از اپ:** یک شماره یا آیدی (تلگرام، بله) برای وقتی سایت در دسترس نیست.
- [ ] **سالن‌های اول:** ۲۰ تا ۵۰ سالن در یک شهر با پروفایل کامل (خدمت، قیمت، عکس، ساعت کاری)، پیش از دعوت مشتری‌ها.
- [ ] **نقشهٔ ایرانی (اختیاری):** کلید API نشان یا Map.ir، تا نقشه جای OpenStreetMap عوض شود.

## تصمیم‌های محصولی که باز مانده‌اند (هنوز ساخته نشده)
- **گشتن بدون ثبت‌نام:** مهمان فهرست و پروفایل سالن‌ها را ببیند و ثبت‌نام فقط موقع «رزرو» خواسته شود.
- **ورود با کد پیامکی (بدون رمز):** وقتی پیامک وصل شد.
- **مهلت جواب سالن:** فعلاً ۱ ساعت (`FRFRO_BOOKING_REQUEST_TIMEOUT_MINUTES`). تا وقتی پیامک وصل نیست، بیشتر کردنش پیشنهاد می‌شود.

## بعد از انتشار (بدهی فنی، بدون عجله)
- تاریخ و ساعت رزرو به نوع واقعی (`date`/`time`) به‌جای متن.
- ارجاع رزرو به آرتیست و خدمت با شناسه به‌جای اسم.
- یکی کردن `salon_bookings` و `artist_bookings`.
- انتقال کدهای «ساخت جدول وسط اجرا» به مایگریشن‌ها.
- کم کردن blur (`backdrop-filter`، ۱۶۴ مورد) روی بخش‌هایی که اسکرول می‌خورند، برای گوشی‌های ضعیف.
- اعلان بومی در اپ اندروید (`docs/ROADMAP.md` بند ۶).
- فضای ذخیرهٔ S3 ایرانی برای عکس‌ها، وقتی دیتابیس بزرگ شد.
